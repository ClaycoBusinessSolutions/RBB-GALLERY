# Clayco exhibition invitation

Public review presentation: https://claycobusinesssolutions.github.io/RBB-GALLERY/

This repository serves the reviewed 20-slide static presentation from `main`. Open the public link; no password or GitHub account is required. The deck is in `deck/` and uses relative asset paths for GitHub Pages.

- G: menu
- F: full screen
- Arrow keys or Previous / Next: advance the presentation
- Seminal projects: each Next click reveals one market of two or three rows of project cards; click any card for details and official sources

Section introductions are labeled as placeholder copy for editorial review. The model-array study is symbolic; final project count, dimensions and venue remain to be confirmed. Spatial concepts are potential opportunities for discussion.

For a local preview, run `python3 launch.py --no-open` and open the loopback URL printed in the terminal.

The meeting recording, transcript, internal review notes and source research are not included in this public build.
